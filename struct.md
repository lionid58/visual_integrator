## проект заключается в визуализации трёхмерного интегрирования

## предпологаеммая структура такая:
1. Визуальный слой - считывает ввод и передаёт его дальше (панель с воводом инструментов и полями для ввода)
2. Блок парсинга - принимает ввод с  полей и собтрает из него математическую задачу задачу
3. блок обработки математики -  принимает задачу строит мат модель  решает её.
4. обработка визуализации - принимает решение задачи обрабатывает его для последующей отрисовки
5. блок отрисовки

## взаимодействие

превые передаточные слои предпологают наличие очереди измениний с возможность её сброса для обработки ввода математических выражений.

блоки начиная с принятия математической задачи принимяю только полностью готовые данные изменение входных приводит к полному перещёту

за исключением блока визуализации он должен при измении поворота или приближения пересчитать имеющиеся, а не делать всё с нуля.
